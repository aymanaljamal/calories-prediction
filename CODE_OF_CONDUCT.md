# Code of Conduct

## Our Commitment

We are committed to providing a welcoming, respectful, and professional environment for everyone participating in the Calories Prediction project.

All contributors, maintainers, reviewers, and participants are expected to communicate respectfully and contribute constructively.

---

## Expected Behavior

Contributors are expected to:

* Be respectful and professional.
* Communicate clearly and constructively.
* Welcome different opinions and perspectives.
* Provide useful and respectful feedback.
* Focus discussions on technical and project-related topics.
* Accept constructive criticism.
* Respect other contributors and maintainers.
* Help create a positive and collaborative environment.

---

## Unacceptable Behavior

The following behavior is not acceptable:

* Harassment or discrimination.
* Personal attacks or insults.
* Threats or intimidation.
* Offensive or inappropriate comments.
* Deliberate disruption of project discussions.
* Sharing private or personal information without permission.
* Trolling or intentionally provoking other contributors.
* Any other behavior that creates an unsafe or hostile environment.

---

## Technical Discussions

Technical disagreements are a normal part of software development.

When discussing technical decisions, contributors should:

1. Focus on the technical problem.
2. Explain their reasoning clearly.
3. Provide evidence or examples when possible.
4. Avoid personal criticism.
5. Consider alternative solutions.
6. Prioritize the quality and maintainability of the project.

---

## Reporting Issues

If you experience or witness inappropriate behavior, please report it privately to the project maintainer.

Reports should include enough information to understand what happened.

All reports should be handled professionally and respectfully.

---

## Maintainer Responsibilities

Project maintainers are responsible for:

* Maintaining a respectful project environment.
* Reviewing reported issues.
* Addressing inappropriate behavior.
* Encouraging constructive collaboration.
* Keeping project discussions professional.
* Taking appropriate action when necessary.

---

## Scope

This Code of Conduct applies to all project-related activities, including:

* GitHub Issues.
* Pull Requests.
* Code reviews.
* Repository discussions.
* Documentation contributions.
* Project-related communication.

---

## Conclusion

Everyone participating in the Calories Prediction project is expected to help maintain a respectful, professional, and collaborative environment.

Thank you for contributing to the project.
